# Buildathon 2027

A responsive, single-page website concept for a two-day college innovation hackathon. It includes event information, project tracks, sample prizes, mentoring guidance, a weekend schedule, a live countdown, and a working browser-only registration demo.

## Run locally

Open `index.html` in a modern browser. This static site uses plain HTML, CSS, and JavaScript; no build tools, server, or dependencies are required.

## Registration demo

- The form validates required fields, email format, duplicate test emails, and the sample registration deadline.
- Submissions are saved in that browser's local storage and can be individually deleted or cleared.
- Entries do not reach an organizer, sync between browsers, or count as real event registrations.
- Use fictional test details only. Local browser storage is not a secure place for real student information.
- The demo accepts up to 20 entries per browser.

The sample event date, Bengaluru location, ₹299 team fee, schedule, and ₹50,000 prize pool are fictional placeholders. Confirm actual event information with the organizers before using this as an event website.

## Publish with GitHub Pages

In the repository settings, open **Pages**, select the `main` branch and `/ (root)` as the deployment source, and save. GitHub Pages will publish `index.html`. This static demo does not include a backend; real, shared registrations require a secure service, privacy notice, and backend validation.
