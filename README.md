# Buildathon 2027

A responsive, single-page website concept for a two-day college innovation hackathon. It introduces the event, project tracks, sample prizes, mentoring guidance, a weekend schedule, and a registration form demo.

## Run locally

Open `index.html` in a browser. The site uses plain HTML, CSS, and JavaScript; no build tools or dependencies are required.

## Features

- Responsive layout for desktop and mobile
- Live countdown to the sample event start date
- Event details, challenge tracks, prizes, and schedule
- Client-side registration form feedback

## Important

This is a front-end demo, not an operating event registration service. The registration form does not submit or save entries. Connect it to a trusted backend before collecting real registrations, and confirm the sample dates, venue, fees, and prizes with the event organizers.

## Publish with GitHub Pages

In the repository settings, open **Pages**, select the `main` branch and `/ (root)` as the deployment source, and save. GitHub Pages will publish `index.html`.
